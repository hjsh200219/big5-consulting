# Big5 Project Operating Rules

## Memory

This repo expects Korean user-facing responses. At session start, check `handoff.md` first, then `.claude-project/HANDOFF.md`. If either exists, read it before doing other work. Before code changes, read the related docs. New features and logic changes require TDD.

## Why

These rules are repeated in `AGENTS.md` and are meant to preserve project context across sessions.

## How To Apply

Use this as the first checklist for every session and before any non-trivial code change.
